# 🚀 Flowtrix AI - Smart Manufacturing Management System

Flowtrix AI is a smart manufacturing management system built using ASP.NET Core Web API, Entity Framework Core and Blazor.  
The system helps engineers manage products, raw materials, inventory, production orders, workflows, reports, and AI-powered insights.

---

# 📌 Features

## 🔐 Authentication & Authorization
- JWT Authentication
- ASP.NET Core Identity
- Role-Based Authorization (Admin / Engineer)

---

## 📦 Product Management
- Add and manage products
- Upload product images
- Product details management

---

## 🧩 Bill of Materials (BOM)
- Define raw materials required for each product
- Specify quantity per unit
- Connect products with inventory materials

---

## 🏭 Inventory Management
- Add and update raw materials
- Track inventory quantities
- Low stock monitoring

---

## ⚙️ Production Order System
- Create production orders
- Automatically calculate required materials
- Validate inventory availability
- Deduct materials from inventory
- Reject orders if stock is insufficient

---

## 🔄 Production Workflow
Production lifecycle includes:
- Pending
- Approved
- In Progress
- Completed
- Failed
- Delivered

Engineers can manually move production between workflow stages.

---

## 📊 Reports & Analytics
The system generates smart reports including:
- Total Orders
- Completed Orders
- Failed Orders
- Total Production
- Top Product
- Most Used Material

---

## 🤖 AI Assistant & Insights
Integrated with Gemini API to provide:
- AI-powered manufacturing insights
- Low stock alerts
- Production recommendations
- Smart business analysis
